# 原生侧栏 UI 重构

开发分支：`refactor/native-sidebar-ui`。目标 DSH 与插件版本仍为 `0.2.2-rc.1`；兼容范围保留 `>=0.2.1-rc.2 <=0.2.1-rc.5 || 0.2.2-rc.1`。本次修改不包含发布、市场索引更新或 DSH 源码改动。

## 行为与实现

- `/side`、`/btw` 完成创建后，通过 `ctx.sidebarRight.openResource()` 打开 DSH 的 `subagentchat` 资源。主会话保留在主列，重开同一子会话复用标签页。
- 命令卡片提供重开入口；原生子代理菜单继续负责历史导航。后台父会话的完成事件不会把子会话打开到其他父会话的侧栏。
- SIDE 的编辑器、发送、队列、转向、停止、流式内容、工具卡片和图片由原生 Session 与聊天 UI 管理。插件不再持有私有聊天缓存、轮询器或续聊输入框。
- BTW 的身份仍来自父会话 `command/done` 生成的 `sidechainModes` 投影。原生侧栏和主视图均使用 composer 扩展隐藏追问输入，运行时保留停止按钮；待处理的交互由宿主处理。身份未加载时先只读，读取失败保留重试入口。
- composer 只在身份投影变化时重新注册；读取状态变化不会反复卸载、挂载加载组件，避免读取失败导致自动重试循环。
- 完整的边界说明和 persona 通过官方 UserText 扩展折叠显示；只在身份匹配的 Sidechain 子会话中生效。问题正文和图片沿用原生渲染，原始消息与模型上下文没有被删改。
- 删除独立面板、宽度和选择状态、活动轮询、私有历史解析、图片加载、文件链接解析、输入框及对应的旧实现测试。

使用官方 CLI 的 Web profile、隔离的 DSH home 与工作目录，以及可见的 Chromium 149 浏览器。模型请求由真实 DeepSeek 官方服务处理，使用 `DeepSeek-V4.1-Flash`；没有使用 mock 模型。

父日志检查确认原生 SIDE 续聊的回答、读文件结果和子代理结算通知没有写入父会话。旧子会话无需迁移；原生菜单、命令卡片、恢复后的标签页均复用已有记录。

类型检查、45 项自动化测试和构建通过。测试保留后端隔离、身份投影和创建观察器的契约，并覆盖原生地址、身份加载、BTW 只读、待处理交互让位及边界文本转换。

本机证据位于忽略目录 `dist/native-sidebar/`：`results.json`、各 RC 的 JSON 结果，以及 `btw.png`、`side-followup.png`、`cold-image.png`、`blank-stop.png`、`main-btw.png`。模型日志和运行环境文件留在忽略目录，不随源码提交。

## 明确边界

- 继承的父历史保留 DSH 原生时间线与折叠规则，没有额外的“全部继承历史”折叠区。完整折叠需要宿主提供相应展示扩展点；本插件不复制原生聊天渲染器，也不直接改写其 DOM。
- BTW 仍是插件提供的 UI 一次性语义。宿主将本地子会话存为 `continuable`，其他客户端或直接 API 调用仍可能续聊。资源地址如实使用宿主 mode。
- 标签页、分栏、全屏、宽度和快捷键由 DSH 维护；原 Sidechain 面板快捷键及手动刷新入口已移除。
- 本次验证覆盖 Web profile 和上述版本。桌面壳与未列出的宿主版本未验证；不保证用旧宿主读取新宿主写出的会话数据。
